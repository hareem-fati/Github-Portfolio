# GitHub Code Repository

This repository contains code samples demonstrating my proficiency in **Stata**, **R**, and **SurveyCTO form design**. Below is a summary of each file and my contributions.

---

## **Stata Code Samples**
1. **Cleaning_Data.do**  
   - **Description**: Cleans and harmonizes district-wise COVID-19 data for Punjab, Pakistan.  
   - **Tasks**:  
     - Importing Excel data into Stata.  
     - Cleaning and merging year-wise datasets.  
     - Transforming cross-sectional data into panel data.  
   - **Contribution**: Sole author.

2. **Data_Visualization.do**  
   - **Description**: Generates graphs for firm-level data, focusing on advertisement methods and firm characteristics.  
   - **Tasks**:  
     - Visualizing firm size, education level, and industry classification.  
     - Creating bar graphs and line charts.  
   - **Contribution**: Sole author.

3. **Data_Visualization-Panel_Data.do**  
   - **Description**: Generates district-wise monthly graphs for COVID-19 cases in Punjab.  
   - **Tasks**:  
     - Creating bar graphs and time-series plots.  
   - **Contribution**: Sole author.

---

## **R Code Samples**
1. **Cleaning_&_Combining_Trade_Data.R**  
   - **Description**: Cleans and combines two trade datasets (USITC and ITPD) to create consolidated sectoral and country-level trade data.  
   - **Tasks**:  
     - Reshaping and merging datasets.  
     - Generating unique pair IDs for merging.  
   - **Contribution**: Sole author.

2. **Descriptive_Stats_&_Visualization.R**  
   - **Description**: Generates descriptive statistics and visualizations for trade data, focusing on Ecuador and Chile.  
   - **Tasks**:  
     - Creating line graphs for trade evolution.  
     - Calculating trade shares and generating summary statistics.  
   - **Contribution**: Sole author.
